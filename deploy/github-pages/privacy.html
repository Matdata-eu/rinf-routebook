Privacy statement

RINF Routebook, public demo on GitHub Pages. Last updated: 15 October 2026.

Who is responsible

This website is published by Matdata, the organisation behind the open-source RINF Routebook project. Matdata is the controller for the personal data described below. For questions about this statement or your data, use the contact details on matdata.eu, or open an issue on GitHub (issues are public: do not put personal data in them).

Hosting on GitHub Pages

The website is hosted on GitHub Pages, a service of GitHub, Inc. (a Microsoft company), which acts as our host. When you open a page, your browser connects to GitHub's servers, and GitHub processes technical data that every web request carries, such as your IP address, the date and time, the requested page and your browser's user agent. GitHub uses this data to deliver the website and to keep its service secure, and may log it. Matdata does not receive these logs. GitHub may process this data outside the European Economic Area, on the basis of the EU-US Data Privacy Framework and the European Commission's standard contractual clauses. See the GitHub General Privacy Statement and data collection on GitHub Pages.

Map tiles and fonts

To draw the map, your browser loads images and fonts directly from these third parties, which therefore also receive your IP address and the usual request data:

  • OpenStreetMap Foundation (tile.openstreetmap.org), for the street map: privacy policy;
  • EOX IT Services GmbH (tiles.maps.eox.at), for the satellite map, only when you switch to it: privacy policy;
  • MapLibre (demotiles.maplibre.org, hosted on GitHub Pages), for the map label fonts.

What this website does not do

  • No cookies, no analytics, no advertising and no tracking.
  • No accounts and no forms: everything you do (choosing operational points, routes, filters) happens in your browser and is not sent to Matdata.
  • Your display settings (which item types you hide) are kept in your browser's local storage, on your own device. You can clear them in your browser at any time.

Railway data

The railway data shown is public data from the Register of Infrastructure (RINF) of the European Union Agency for Railways, downloaded when the website is built. It describes infrastructure, not people.

Legal basis and retention

The processing of the technical request data is needed to deliver and secure the website, which is our legitimate interest (Article 6(1)(f) GDPR). Matdata itself does not store it. How long GitHub and the map providers keep their logs is set out in their own privacy statements.

Your rights

Under the GDPR you have the right to access, correct and erase your personal data, to restrict or object to its processing, and to data portability. To use these rights, contact Matdata as described above; for the logs kept by GitHub or the map providers, you can also contact them directly. You have the right to lodge a complaint with a data protection authority, in particular in the EU member state where you live or work.

Changes

We may update this statement when the website changes. The current version is always on this page, and its history is in the project repository.
