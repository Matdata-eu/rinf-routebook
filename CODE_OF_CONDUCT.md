# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful and constructive in issues, pull requests and discussions; welcome newcomers; focus on the work. Harassment, personal attacks and discrimination are not accepted.

Report a problem to <mathias@matdata.eu>. Reports are handled confidentially, and the maintainers decide on the consequences, which can go from a warning to a ban from the project.
